# Steady — AI Lifestyle Coach (Prototype)

An AI agent that improves your lifestyle **one small step at a time**, in phases:

1. **Sleep first.** Nothing else is coached until your self-reported sleep is stable
   (hit your target on 5 of the last 7 days).
2. **Habit swap.** Replace one bad habit (doomscrolling, late-night gaming) with a hobby
   you chose — gym, a sport, chess, a community.
3. **Long-term goal.** Lose weight or learn a skill — coached slowly and sustainably,
   one micro-action per day.

Every daily check-in (sleep hours, habit swap yes/no, goal action yes/no, an optional
note) gets a short coaching message and **exactly one** small action for the next
24 hours. No wearables — you tell the agent, the agent tracks what you report.

See [BRAINSTORM.md](BRAINSTORM.md) for the full product thinking.

## Run it

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
# open http://127.0.0.1:8000
```

The coach's voice is generated by Claude (`claude-opus-4-8`) when `ANTHROPIC_API_KEY`
is set in the environment. Without a key, the prototype falls back to rule-based
coaching messages, so the demo always works.

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # optional, enables the LLM coach
```

## Architecture

```
app/
  main.py       FastAPI routes: /api/state, /api/profile, /api/checkin
  coach.py      Phase logic, streaks, Claude integration + rule-based fallback
  database.py   SQLite (single-user prototype): profile + daily check-ins
  static/       Vanilla HTML/CSS/JS single-page UI
```

State is stored in `coach.db` (created on first run, git-ignored).

## Trying the phase progression quickly

Phases are computed from check-in history, one check-in per calendar day. To demo
phase 2/3 without waiting a week, insert backdated rows into `coach.db`:

```bash
python - <<'PY'
import sqlite3, datetime
conn = sqlite3.connect("coach.db")
for i in range(1, 8):
    day = (datetime.date.today() - datetime.timedelta(days=i)).isoformat()
    conn.execute("INSERT OR REPLACE INTO checkins (day, sleep_hours, habit_replaced) VALUES (?, 8, 1)", (day,))
conn.commit()
PY
```
